# Kandela Kulture — Freeform Asset Archive

This directory serves as the curated repository for Kandela Kulture's brand design system, vector graphics, identity lockups, specification sheets, and community gathering photography. All raster imagery is refined to modern, high-performance WebP format (saving over 20 MB of repository storage and load time).

---

## Directory Organization

```
public/assets/freeform/
├── README.md                           # Master archive catalog and asset guide
├── brand/                              # Official logo lockups, icons, badges, and vector marks
├── graphics/                           # Decorative vector elements (arrows, bursts, dividers, underlines, scribbles)
├── specs/                              # Design system sheets, typography specimens, moodboards, and apparel specs (WebP)
└── photos/                             # Curated community gathering photography (WebP, organized by event date)
```
